# Airline reference data

## Architecture (one source, never a second airline table)

| Piece | Where |
|---|---|
| The table | `Airline` (Prisma): `iata` (unique, 2 characters), `icao` (3 letters), `name`, `country`, `logoUrl`, `isActive`. `FlightSegment.airlineId` points at it; `Booking.airlineConfirmations[].airlineIata` stores a code that is resolved through it. |
| Baseline data | OpenFlights `prisma/seed-data/airlines.dat` (ODbL, years old). |
| Curated corrections | `prisma/seed-data/airlines-curated.json` — the only hand-maintained airline file. |
| Bundled copy for a brand-new database | `src/data/reference/airlines.json`, generated by `npm run generate:reference-json` (baseline → `sanitizeAirlineRows` → `applyCuratedAirlines`). `ensureReferenceDataSeeded()` loads it into an empty table. |
| Fix for an EXISTING database | migration `20261005000100_airline_reference_refresh`, **generated from the same JSON** by `npx tsx prisma/seed-data/generate-airline-migration.ts`. |
| Logos | no per-airline files: `airlineLogoUrl(iata)` derives `https://images.kiwi.com/airlines/64x64/<IATA>.png` (an explicit `Airline.logoUrl` wins). Codes the CDN has no usable image for are listed in `IATA_CODES_WITHOUT_CDN_LOGO` and fall back to the boxed code on screen / no `<img>` in email. |
| Picker | `searchAirlines()` — accent-insensitive; ranking: exact IATA, exact name, exact ICAO, name prefix, word prefix, contains (`src/lib/airline-search.ts`). |
| Code resolver | `resolveAirlineCodes()` — exact IATA or ICAO, active carrier preferred. Used by the GDS paste, booking airline confirmations and every email. |

Never edit `airlines.json` or the migration SQL by hand: edit `airlines-curated.json`, then regenerate both.

## What the audit found (baseline = the data the app shipped with)

The OpenFlights file predates many airlines and, more importantly, **IATA codes are recycled**: a code that once belonged to a defunct carrier was later issued to a different, current one. Because `iata` is unique, the old row kept the code, so today's airline could not be found (typing "Pegasus", "Volotea", "SpiceJet", "Jazeera", "Starlux", "Air Premia" … found nothing; the code `PC` resolved to *Air Fiji*, `VJ` to *Jatayu*, `XP` to *Xtra Airways*, `4Y` to *Airbus France*). About 75 airlines that ceased long ago were still flagged active, and a handful of rows carried placeholder codes (`--`, `??`, `8z`).

| | Before | After |
|---|---|---|
| Airline rows | 5,744 | 5,861 (database) / 5,817 (bundle) |
| Rows with an IATA code | 1,120 | 1,110 (placeholders cleared) |
| Active airlines with an IATA code | 773 | 800 |
| Placeholder / malformed IATA values | 15 | 0 |
| Malformed ICAO values | 48 | 0 |
| Duplicate IATA codes | 0 (database-enforced) | 0 |
| Active airlines sharing an ICAO | 2 | 0 |
| Curated entries | – | 211 (111 added, 46 existing code-less rows given their IATA, 34 renamed/re-activated, 20 relabelled in place) |
| Recycled codes freed from a previous holder | – | 146 (every previous holder kept, inactive, no code) |
| Ceased airlines marked inactive | – | 66 + the freed holders |
| Rows deleted | – | **0** |
| Curated airlines with no usable CDN logo | – | 4 of 211 (MX, HJ, B9, 3X) → existing fallback |

Duplicate names (case-insensitive): 63 before — unchanged in kind; these are distinct historical carriers sharing a trade name. Among **active** rows the picker shows 6 names twice (5 before); the remaining ones are different airlines (e.g. Sky Express in Greece and in Russia).

## Verification protocol (nothing inferred)

Every curated entry has an IATA **and** ICAO that match in two independent sources — Wikipedia's *List of airline codes* (A–Z, 0–9) and the airline's own Wikipedia infobox — and the logo CDN was asked for every code (HTTP 200 + image bytes). Entries that failed were dropped or corrected (three recalled ICAO codes were wrong and caught this way: Norse Atlantic `NBT`, AJet `TKJ`, Arajet `DWI`). Sources are listed in the JSON's `_sources`. This is **broad, high-quality coverage — not "all airlines"**: it adds the operating international, regional and low-cost carriers a travel CRM meets; thousands of tiny, cargo-only and historical operators are deliberately not added.

## How history is protected

- The migration contains no `DELETE`, `DROP` or `TRUNCATE`; it never changes an `id`, so every `FlightSegment.airlineId` keeps pointing at the row it was saved with.
- **Recycled code (unrelated airline):** the old holder keeps its row, name and ICAO, becomes inactive and loses only the code; the real holder gains it.
- **Same company renamed / successor (e.g. Brussels Airlines, Norwegian, Envoy, Endeavor, ITA Airways):** the row is relabelled in place and, when the old name differs materially, the previous identity is kept as an inactive record.
- Inactive airlines still resolve by code for historical records; they are only hidden from the picker.
- Each airline is applied in its own sub-transaction and the whole script is idempotent (proved on a real PostgreSQL: a second run changes nothing).
- A segment that was *already saved* against a recycled row (for example a 2026 VietJet flight saved while `VJ` pointed at "Jatayu Airlines") keeps showing that row. To find those in production:

```sql
SELECT a.id, a.name, a.icao, count(*) AS segments
FROM "FlightSegment" s JOIN "Airline" a ON a.id = s."airlineId"
WHERE a.iata IS NULL AND NOT a."isActive"
GROUP BY a.id, a.name, a.icao ORDER BY segments DESC;
```

## Known limitations

- No alias table exists; accent-folding and ranking cover the common cases ("aeromexico" → Aeroméxico) but a brand name that differs from the legal name still has to be typed as the canonical name or code.
- The picker's "no query" list is the first ten active airlines alphabetically (unchanged).
- Logo coverage depends on a third-party CDN; the fallback is the boxed IATA code.
- Production's own `Airline` contents and its historical references could not be inspected from this repository — run the query above.
